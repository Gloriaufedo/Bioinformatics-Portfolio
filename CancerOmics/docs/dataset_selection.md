# Dataset Selection

## Project

Pan-Cancer Transcriptomic Determinants of Ferroptosis Sensitivity

## Primary Research Question

Which transcriptomic programs distinguish ferroptosis-sensitive from ferroptosis-resistant cancer cell lines across multiple tumour types?

## Selected Datasets

### CCLE RNA-seq

Purpose:
Gene expression profiles for cancer cell lines.

### PRISM Drug Repurposing

Purpose:
Drug response measurements used to identify ferroptosis-sensitive and resistant cell lines.

Selected compounds:

- Erastin
- RSL3

### DepMap Metadata

Purpose:
Cell line annotations including tissue origin and disease classification.

## Rationale

Using multiple pharmacogenomic resources enables robust integration of transcriptomic, pharmacological and biological metadata while allowing reproducible downstream analyses.
